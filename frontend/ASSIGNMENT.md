## 任务

在当前 `frontend/` 目录内实现企业级 AI 加密量化交易控制台的首轮可运行前端骨架。

## 技术与边界

- 使用 React + TypeScript。
- 只修改 `frontend/`，不要修改 `backend/` 或 `ARCHITECTURE.md`。
- 默认中文界面，黑白灰高级金融科技视觉。
- 不使用赛博朋克风格，不伪造真实交易连接。
- 可以使用契约对齐的 mock 数据。
- 不得把交易、风控和订单规则复制到前端；前端只负责呈现和交互。

## 首轮页面

1. 总览 Dashboard：权益、PnL、风险状态、系统健康、告警。
2. 市场数据：行情、盘口、成交、资金费率和数据质量。
3. 量化研究：策略列表、版本、回测任务和结果摘要。
4. 交易执行：订单、成交、持仓和对账。
5. 风控中心：风险预算、规则结果、熔断和审批状态。
6. Agent 控制台：任务、工具权限、运行记录和审批。
7. 系统设置：账户、交易所连接、角色、权限和审计。

## 验收要求

- 工程可以启动。
- 路由和导航完整。
- 页面具有加载态、空态和错误态。
- 组件风格统一，图表和数据卡片可复用。
- 页面层次清晰，桌面端控制台布局稳定。
- 使用 mock 数据时明确标注为模拟数据。
- 完成后列出修改文件、启动命令、验证结果和已知问题。
